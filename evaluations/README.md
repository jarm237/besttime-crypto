# Evaluation Reports

Thư mục này gom các báo cáo đánh giá và assessment dùng để rà soát chất lượng hệ thống, module và luồng quyết định.

| Tài liệu | Nội dung |
|---|---|
| `signal_detection_and_scoring_assessment.md` | Đánh giá luồng phát hiện tín hiệu, score, CausalGate và AutoTrader gate |
| `alternative_module_evaluation.md` | Đánh giá module Alternative Data |
| `kelly_fraction_evaluation.md` | Đánh giá Kelly fraction, risk gate và sizing readiness |
| `ml_model_evaluation.md` | Đánh giá ML model |
| `system_evaluation_report.md` | Đánh giá tổng thể hệ thống |
| `implementation_plan_comparison.md` | So sánh implementation plan |
